# FM 2-0 Knowledge Graph Research

Research artifacts from a local Ollama/Llama 3.2 3B experiment comparing **fixed predicate** and **model-generated predicate** descriptions of term pairs. Terms and definitions were previously extracted into a CSV from FM 2-0 and treated as the source vocabulary; the model inferred candidate relations from those definitions and its learned knowledge rather than requiring PDF passage co-occurrence.

## Experiment snapshot

- 49 unique CSV terms in the working vocabulary (from 50 source records).
- First extraction retained 18 candidate relationships; a subsequent fixed-predicate expansion retained **70** candidate relationships, using **15** distinct predicates from the allowed set of 19.
- The dynamic pass reconsidered the same 70 subject-object pairs without showing the original fixed predicates. **69** responses passed structural validation, and **1** failed.
- The dynamic pass used **39** unique predicate names. **62** of the 69 accepted outputs had a predicate name different from the fixed baseline.
- **Different predicate names do not establish different semantics or correctness.** Results have not been independently verified against FM 2-0 or expert-reviewed.

## Cautions

This dataset contains **LLM-generated hypotheses**, not validated doctrinal facts. Some predicates or relationship directions may be inappropriate, and the validation was primarily structural. The dynamic phase was conditioned on subject-object pairs generated by the fixed phase, so it tests predicate variation on those pairs, not independent relationship coverage.

The **source CSV was not included in the uploaded experiment ZIP** and is not committed here. The checkpoint includes definitions associated with selected relationships; review data-sharing and source rights before public distribution.

## Reproduction

Open the notebook in Google Colab with T4 GPU, start the Ollama server, upload the CSV (term in column A and unmodified definition in column B), run the small test batch, and then run extraction. For a complete reconstruction of the predicate-variance study, use the additional experiment code preserved in `research/variance_experiment_method.md` and the original checkpoint. The output may vary because LLM generation is stochastic.
